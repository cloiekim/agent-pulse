Agent Pulse — 테스트 버전
=========================

여러 AI 에이전트(Claude Code, Codex, 브라우저 탭)가 지금 뭘 하고 있는지
메뉴바에서 한눈에 보는 앱입니다.

제일 중요한 건 이겁니다:
에이전트가 "이 명령 실행해도 될까요?" 하고 멈춰 있으면 바로 알려줍니다.
Claude Code 기본 알림은 60초가 지나야 오는데, 이건 6초면 옵니다.


설치 (2분)
----------

  ./install.sh

이게 다 합니다. 물어보는 대로 답하시면 됩니다.

설치 후 메뉴바 오른쪽에 파형 아이콘(⌁)이 생깁니다.
안 보이면 메뉴바가 꽉 찬 겁니다 — 다른 아이콘을 ⌘ 누른 채 드래그해서
자리를 만들거나, 앱 설정에서 "Icon only" 로 바꾸세요.


브라우저 탭도 보려면 (선택, 3분)
--------------------------------

claude.ai / chatgpt.com 탭까지 보려면 크롬 확장을 넣어야 합니다.

  1. Chrome 에서 chrome://extensions 열기
  2. 오른쪽 위 "개발자 모드" 켜기
  3. "압축해제된 확장 프로그램을 로드합니다" → chrome-extension 폴더 선택

터미널만 쓰신다면 안 하셔도 됩니다.


잘 되고 있는지 확인
-------------------

메뉴바 아이콘을 클릭하면 팝오버가 열립니다.
아무것도 안 돌고 있을 때 아래처럼 연결 상태가 보입니다:

  ✓ Claude Code
  ✓ Codex
  ⌁ Browser tabs      ← 체크가 없으면 그 부분은 안 잡히는 중

체크가 없는 항목은 그 경로가 아직 연결 안 된 것뿐이고,
나머지는 정상 동작합니다.


아직 안 되는 것 (알고 있습니다)
-------------------------------

· Claude 데스크톱 앱(Cowork) 작업은 안 보입니다
  → 클라우드에서 실행돼서 이 Mac 에 흔적이 없습니다. 방법이 없습니다.

· 알림 왼쪽 아이콘이 빈 네모입니다
  → 정식 서명을 안 해서 그렇습니다. 배포 때 해결됩니다.

· 알림을 누르면 앱/터미널까지는 가는데, 그 안의 특정 대화·탭까지는
  아직 못 갑니다.

· ChatGPT 사용량(토큰 잔량)은 안 나옵니다. OpenAI 가 공개를 안 합니다.


문제가 생기면
-------------

로그가 여기 쌓입니다:

  ~/.agent-pulse/debug.log

뭔가 이상하면 이 파일이랑 "무엇을 하려다 그랬는지" 한 줄만 주시면 됩니다.
스크린샷이면 더 좋고요.

특히 이런 게 있으면 꼭 알려주세요:

  · 승인 대기인데 알림이 안 왔다      ← 제일 중요
  · 안 멈췄는데 알림이 왔다 (오탐)     ← 이것도 중요
  · 글자가 안 보이거나 잘린다
  · "이게 무슨 뜻이지?" 싶은 문구


끄기
----

메뉴바 아이콘 → 톱니(⚙) → Quit

완전히 지우려면:

  ./uninstall.sh

훅 설정까지 원래대로 되돌립니다.
